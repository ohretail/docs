# Security

Please don't report security problems in public issues or discussions.

Report them privately through
[GitHub's private vulnerability reporting](https://github.com/ohretail/docs/security/advisories/new),
or through [ohretail.com/contact](https://ohretail.com/contact). This covers
every Oh! Retail app, including Oh! Retail POS, installed registers, and Simple
Scheduler.

Tell us what you found, how to reproduce it, and which app and version it
affects. We'll confirm we've received it and keep you updated while we fix it.

If you've accidentally posted something private, such as a password or a
register setup file, contact us straight away so we can remove it and replace
the credential.
