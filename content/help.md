Questions, problems, and ideas for every Oh! Retail app, including Oh! Retail
POS and Simple Scheduler, live in one public GitHub repository,
[ohretail/docs](https://github.com/ohretail/docs). You need a free GitHub account
to post.

## Ask a question

Use [Discussions](https://github.com/ohretail/docs/discussions) for "how do I…?"
questions, setup advice, and ideas. Search first: someone may have asked
already. Other stores can answer too.

- [Q&A](https://github.com/ohretail/docs/discussions/categories/q-a): how to do
  something, or whether the app can.
- [Ideas](https://github.com/ohretail/docs/discussions/categories/ideas):
  features and changes you'd like.

## Report a problem

[Open an issue](https://github.com/ohretail/docs/issues/new/choose) when something
is broken or doesn't work as these guides describe. A good report has:

1. Which app, and for a register, whether it's in a browser or installed.
2. What you did, step by step.
3. What you expected, and what happened instead, with the wording of any
   message. Leave out names, account details, or anything else private that the
   message shows.
4. The version, for installed registers, from **Back Office → Local registers**.

Screenshots help. Crop or blur anything private first.

## Keep private things private

Issues and discussions are **public**. Anyone on the internet can read them, and
they stay searchable. Never post:

- Passwords, PINs, invitation or reset links, or register **setup files**.
- Customer names, phone numbers, emails, or account balances.
- Card numbers, or receipts and screenshots that show them.
- Log files such as `pos.log`. If we need one, we'll tell you how to send it
  privately.

For anything private, such as billing, account access, or a problem that
involves customer data, [contact us directly](https://ohretail.com/contact).

## Security issues

If you think you've found a security problem, don't open a public issue. Report
it privately through
[GitHub's private reporting](https://github.com/ohretail/docs/security/advisories/new)
or [contact us](https://ohretail.com/contact).

## Fix these guides

Found a mistake here? Every guide has **Suggest an edit on GitHub** at the
bottom. You can also report a problem with a page from the same place.
