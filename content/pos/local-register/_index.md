An installed register is Oh! Retail POS as a Windows app. It keeps a full copy of
your store database on the register PC, so it keeps selling when the internet
goes down and uploads everything once the connection is back.

Installed registers are in **pilot**: they run in real stores, and we're still
improving them. Tell us what you find in
[Discussions](https://github.com/ohretail/docs/discussions) or by
[reporting a problem](https://github.com/ohretail/docs/issues/new/choose).

## How it differs from a browser register

| | Browser register | Installed register |
| --- | --- | --- |
| Needs the internet to sell | Yes | No |
| Sign-in | Email and password | Cashier name and PIN, or email and password |
| Printers | Separate printer setup | Built in, chosen at install |
| Customer screen | Open it yourself | Opens by itself on the second monitor |
| Updates | Always current | Download by themselves; apply with **Restart POS** |

You can run both kinds in one store. Once a register number is installed on a
PC, though, it can't be used from a browser any more.
